A safety fix for Lyrics Synced with Music: a misbehaving album-art server can no longer exhaust the shell's memory. Nothing changes in how the panel looks or works.

**Update** with `omarchy plugin update crmne.lyrics`, or install with `omarchy plugin add https://github.com/crmne/omarchy-lyrics.git --enable --yes`.

## Fixed

- **The cover in the panel header can no longer take the shell down.** The panel used to hand the cover URL from the player straight to Qt, which holds a whole https response in memory before decoding it, however large. While the panel is open, covers are now downloaded by a small helper with a hard limit of 16 MiB and 20 seconds into a private cache under `~/.cache/omarchy/lyrics/artwork`, and the panel loads them from there. Covers the player keeps on disk are shown only when they are regular files within the same limit, and the cover URL stays off the process list. Reported by @HANCORE-linux in [omacom/omarchy-plugin-marketplace#12068](https://github.com/omacom/omarchy-plugin-marketplace/issues/12068). By @crmne.

## Known limitations

- A cover larger than 16 MiB is not shown; the header shows the title and artist on their own.
