A privacy fix for Lyrics Synced with Music: what you are listening to no longer shows up in the process list for other users on the machine, and a lookup can no longer hang on a slow server.

**Update** with `omarchy plugin update crmne.lyrics`, or install with `omarchy plugin add https://github.com/crmne/omarchy-lyrics.git --enable --yes`.

## Fixed

- **The song you are playing stays private.** Each lookup used to pass the artist, title, album and length to the fetch helper as command-line arguments, which any user on the same machine can read from the process list while the request runs. They now travel in the helper's environment, which only you can read, and its command line holds only fixed paths and flags. Found while preparing the plugin for marketplace review. By @crmne.
- **A lookup always finishes.** The helper now gets 30 seconds for the whole request and reports a timeout after that, so a server that answers a byte at a time can no longer keep it running. The shell also stops it a few seconds later if it does not stop itself. By @crmne.
